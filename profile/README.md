# Eden Street

Eden Street builds per-client data platforms in the client's own cloud: every source
system loaded into one warehouse, every business entity matched across every source
into one record, and the same data reachable through Claude/ChatGPT (MCP), dashboards,
Excel, and scheduled reports.

Each client owns their own cloud account and all code; Eden Street builds, trains, or
manages, depending on the engagement tier.
